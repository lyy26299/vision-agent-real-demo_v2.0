- ✓ Python 3.13.5 已安装

## 🎯 现在就运行

### 方式 1: 使用启动脚本（推荐）

```bash
./run.sh
```

### 方式 2: 使用 uv 直接运行

```bash
uv run python vision_agent_demo.py
```

## 📱 启动后会发生什么

1. **YOLO 模型下载**（仅首次）
   - 大约 6MB，需要 10-30 秒
   - 进度会显示在终端

2. **创建 Stream 视频通话**
   - Agent 会生成一个唯一的通话 ID
   - 终端会显示通话链接

3. **自动打开浏览器**
   - 进入视频通话界面
   - **重要**: 点击"允许"摄像头和麦克风权限

4. **Agent 加入通话**
   - 你会听到 AI 的语音问候
   - 终端显示 "Agent 已加入通话"

5. **开始交互**
   - 对着摄像头做动作
   - AI 会实时分析并语音反馈

## 🎬 试试这些动作

## ⚠️ 常见启动问题

### 问题 1: "ModuleNotFoundError: No module named 'vision_agents'"

**解决方案**:
```bash
# 必须使用 uv run
uv run python vision_agent_demo.py

# 或者激活虚拟环境
source .venv/bin/activate  # macOS/Linux
python vision_agent_demo.py
```

### 问题 2: Stream 连接失败

**检查**:
```bash
# 查看 .env 文件中的密钥
cat .env | grep STREAM
```

确保：
- 密钥没有引号
- 没有多余空格
- 复制的是完整密钥

### 问题 3: Gemini API 限额

如果提示 API 限额：
- 检查 https://ai.google.dev/ 的配额
- 或在 `vision_agent_demo.py` 中修改 `fps=10` 改为 `fps=3`

### 问题 4: 浏览器没自动打开

**手动访问**:
1. 查看终端输出
2. 找到类似这样的链接：
   ```
   https://getstream.io/video/demos/join/...
   ```
3. 复制到浏览器打开

### 问题 5: 摄像头无法访问

- Chrome/Edge: 设置 → 隐私和安全 → 网站设置 → 摄像头
- 允许 `getstream.io` 访问摄像头
- 刷新页面
